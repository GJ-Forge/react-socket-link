    Class LogicalConnection<I, O>

    Owns a stable connection identity across replaceable native WebSockets.

    Remarks

    Retains listeners and queued messages across reconnects. Transport replacement closes the old socket first; server messages during the gap may be lost. Call dispose when a standalone connection is no longer needed.
